# TehnoMerkez

Система управления компьютерным сервисным центром: клиенты, специалисты, заказы, история ремонта, отслеживание по номеру и коду, отчёты и печать квитанций.

## Запуск

Из этой папки: `npm start`, затем http://127.0.0.1:4173. Установка зависимостей и сборка не требуются.

Проверки бизнес-логики: `npm test`.

## Работа

1. Добавьте клиента и специалиста.
2. Создайте заказ с устройством, неисправностью, сроком и стоимостью.
3. Изменяйте этапы ремонта, добавляя комментарии в историю.
4. Используйте номер заказа и код из квитанции для отслеживания.
5. Выгружайте отчёты в CSV и резервные копии в JSON через «Управление данными».

## Хранение

При первом открытии рабочее пространство пустое. Существующие записи предыдущей версии сохраняются: внутренний ключ localStorage оставлен прежним для совместимости. Автоматическое заполнение примерами и сброс к примерам отключены.

Данные хранятся только в текущем браузере. Для переноса используйте JSON-копию. Общего серверного хранилища, учётных записей сотрудников, отправки сообщений и платёжного учёта нет. Проверка по коду работает с локальными записями и не является отдельным публичным клиентским порталом.

Русский, туркменский и английский интерфейсы. Для PDF используйте штатную печать браузера. Стоимость выданных работ в отчёте не означает сумму полученных оплат.
